# OOP in Practice

A Java study project that models a bootcamp with courses, mentorship sessions, and enrolled developers. Based on DIO's object-oriented programming challenge.

## Stack
- Java
- Object-oriented programming and Collections

## Run
Open the project in a Java IDE (such as IntelliJ IDEA), configure a JDK, and run the `Plataforma` class at `poo-na-pratica/src/Plataforma.java`.
