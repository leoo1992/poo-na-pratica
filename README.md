# POO na prática

Projeto de estudo em Java que modela um bootcamp com cursos, mentorias e desenvolvedores inscritos. Exercício baseado no desafio de Programação Orientada a Objetos da DIO.

## Stack
- Java
- Orientação a objetos e Collections

## Como executar
Abra o projeto em uma IDE Java (por exemplo, IntelliJ IDEA), configure um JDK e execute a classe `Plataforma`, localizada em `poo-na-pratica/src/Plataforma.java`.
